# Afdeling C

Der er 8 stuer på afdeling C, som fortrinsvis fordeler sig indenfor to målgrupper. Borgerne kan både være unge og gamle.

## Målgruppe 1

Borgere med kræft, som har behov for en rehabiliterende og palliativ indsats (borgere, som modtager kemokur eller strålebehandlinger og ikke kan være hjemme, borgere med nedsat funktionsevne eller palliative problemstillinger)

## Målgruppe 2

Borgere i terminalfasen, som har behov for palliativ indsats. Enkelte af disse borgere kommer videre på Hospice, andre dør på Lysningen.
