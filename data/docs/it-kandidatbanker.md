# IT kandidatbanker

Du kan oprette dig i én eller flere af vores IT kandidatbanker, hvis du er interesseret i at blive kontaktet, når virksomheder søger nye medarbejdere.

Virksomhedskonsulenterne inden for IT bruger jobsøgendes CV'er via Jobnet og kandidatbankerne, når vi har konkrete job, løntilskudsstillinger eller virksomhedspraktikker.

Vi har oprettet seks kandidatbanker indenfor IT området, som du kan læse mere om her på siden, inden du tilmelder dig.

## for dig, som er ledig

Tilmeld dig en eller flere af nedenstående kandidatbanker

Læs mere om den enkelte kandidatbank og find den, der passer bedst til dig og dine kompetencer:

IT Support og Systemadministration

Kommunikation - SoMe - Marketing

Se også vores IT jobbank, hvor du finder ledige job inden for IT-branchen
