# Identitetstyveri

### Hotlinen kan hjælpe med:

- Hvordan du kan stoppe misbruget.

- Hvad du kan gøre for at komme videre.

- Hvem, der er relevante for dig at kontakte.

Helt konkret kan hotlinen ikke overtage din sag, men kan skabe et overblik og hjælpe dig med blandt andet:

- Spærre MitID, oprette kreditadvarsel, anmelde til politiet, se i hændelseslog, undersøge om der er oprettet uønskede lån eller foretaget ændringer på NemKonto, og ikke mindst rådgive om det videre forløb for at få pengene tilbage herunder samle dokumentation.

Læs mere identitetstyveri og online svindel.
