# Vejarbejde i Odense fra 03.11

Vejarbejde i Odense fra 03.11

## Der startes op på vejarbejde flere steder i Odense i uge 45. Læs mere nedenfor.

**Abels Allé - Vejdarbejde 3/11-21/11**

Der laves asfaltbump på Abels Allé. Arbejdet forventes at tage 2 - 3 dage, i perioden fra. 3. november - 21. november. Der spærres for gennemkørsel mens arbejdet udføres, beboerkørsel er dog tilladt. Omkørsel kan foretages via Faaborgvej, Sanderumvej, Væddeløbsvej og Prins Haralds Allé.

**Kærvej - Vejarbejde 3/11-21/11**

Der laves asfaltbump på Kærvej. Vejen spærres for gennemkørsel mens arbejdet udføres. Beboerkørsel er tilladt. Omkørsel kan foretages via Ørbækvej, Hvilehøjvej og Over-Holluf-Vej.

**Dronning Olgas Vej 3/11-7/11**

Der udføres reparation af vejbrønd og kloakledning på Dronning Olgas Vej. Vejen spærres for gennemørsel mens arbejdet udføres. Omkørsel kan foretages via Johannevej.

**Poppelvej - Vejarbejde 3/11-7/11**

Der udføres reparation af sætningsskade på Poppelvej. Vejen spærres for gennemkørsel mens arbejdet udføres. Omkørsel kan foretages via Helgavej, og Birkevej.
