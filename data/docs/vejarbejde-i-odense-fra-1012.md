# Vejarbejde i Odense fra 10/12

Vejarbejde i Odense fra 10/12

## Der startes op på vejarbejde flere steder i Odense. Læs mere nedenfor.

**Østerbæksvej - Vejarbejde 10/12-11/12**

Der etableres vejbump på Østerbæksvej. Vejen spærres for gennemkørsel i retning mod rundkørslen. Omkørsel kan foretages via Kragsbjergvej og Bjerregaardsvej.

**Fredensgade - Trafikinfo 11/12**

Der udføres kranarbejde på Fredensgade ved nr. 33, fra kl. 07.00 - kl. 16.00. Mens arbejdet udføres er vejen spærret for gennemkørsel. Omkørsel kan foretages via Allégade, Hjallesevej og Fredensgade.
