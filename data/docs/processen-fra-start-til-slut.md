# Processen fra start til slut

## Signatur forklaring:

Odense Kommune

Boligorganisation

Skema A, B og C

## Processen fra start til slut

Boligkvoter udbydes

Projektmateriale indsendes

Projektet er modtaget og vurderes

Politisk vedtagelse og accept af boligkvoter

Politisk forhåndsgodkendelse

Evt. lokalplanlægning

Projekt og økonomi sikres

Politisk godkendelse af Skema A

Planlægning og udbud

Myndighedsbehandling\*

Godkendelse af skema B

Håndværkerne i gang

Boligerne bebos

Godkendelse af skema C

\* Ved særlige forhold kan skema B gives før byggetilladelsen (med forbehold for, at byggetilladelsen kan gives).
