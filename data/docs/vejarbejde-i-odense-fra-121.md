# Vejarbejde i Odense fra 12/1

Vejarbejde i Odense fra 12/1

Der startes op på vejarbejde flere steder i Odense. Læs mere nedenfor.

**Lindvedvej - Vejarbejde 12/01 - 16/01**

Der udføres ombygning af overkørslen på Lindvedvej ved jernbanen. Vejen spærres for gennemkørsel, mens arbejdet udføres.

**Jernbanegade - Vejarbejde 14/01-4/02**

Der udføres tryghedsskabende foranstaltninger på Jernbanegade ved Grand Hotel. Der spærres for gennemkørsel, mens arbejdet udføres.
