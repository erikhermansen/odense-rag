# Evaluering af fodstatus

Tilskuddet ydes til almindelig fodpleje (fodbad og klipning af tånegle og lignende) og egentlig fodbehandling, som patienten ikke selv kan udføre, og som ikke er omfattet af Sundhedslovens kapitel 15 eller anden lovgivning (fx diabetes, bøjlebehandling for nedgroede negle, svær leddegigt og arvæv efter strålebehandling).

Du skal som behandler logge ind med MitID Erhverv. Du må IKKE anvende dit private MitID.
