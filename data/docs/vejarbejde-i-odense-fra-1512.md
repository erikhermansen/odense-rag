# Vejarbejde i Odense fra 15/12

Vejarbejde i Odense fra 15/12

## Der startes op på vejarbejde flere steder i Odense. Læs mere nedenfor.

**Melbyesvej - Vejarbejde 15/12-19/12**

Der udføres reparation af kloak på Melbyesvej. Vejen spærres for gennemkørsel ved arbejdet. Omkørsel kan foretages via Eckersbergsvej/Rødegårdsvej og Købkesvej/Rødegårdsvej.

**Vikingevej - Vejarbejde 15/12-19/12**

Der udføres kloakarbejde på Vikingevej. Vejen spærres for gennemkørsel mens arbejdet udføres. Omkørsel kan foretages via Skt. Jørgens Gade, Ejby Møllevej og Jomsborgvej.
