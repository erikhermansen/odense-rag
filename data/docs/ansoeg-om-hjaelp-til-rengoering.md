# Ansøg om hjælp til rengøring

## Hvordan ansøger du?

Du kan søge via den grønne knap i selvbetjeningsboksen: Ansøg om hjælp til rengøring.

Modtager du hjemmehjælp, kan du kontakte din hjemmeplejegruppe.

Modtager du ingen hjælp, så kontakt INDGANGEN.
