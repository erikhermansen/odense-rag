# Vejarbejde og trafikinfo i Odense fra 2. november 2026

## Trafikinfo og opstart af vejarbejde flere steder i Odense. Læs mere nedenfor.

**Enghavevej - Vejarbejde 2. - 13. november**

Der etableres nyt fjernvarmeskab på Enghavevej. Vejen spærres for gennemkørsel, mens arbejdet udføres. Omkørsel kan foretages via Hunderupvej, Helgavej, Linde Allé og Hjallesevej.

**Odensegyden - Vejarbejde 2. - 4. november**

Der skiftes en defekt vejbrønd på Odensegyden ved nr. 11. Vejen spærres for gennemkørsel, mens arbejdet udføres. Omkørsel kan foretages via Søhusvej, Korsgade og Mellemgyden.

**Kongelysevej - Vejarbejde 2. - 6. november**

Der udføres reparation af kloakstikledning på Kongelysvej. Vejen spærres for gennemkørsel, mens arbejdet udføres. Omkørsel kan foretages via Døckerslundsvej, Paaskeløkkevej og Solsikkevej.

**Pilevangen - Vejarbejde 3. - 5. november**

Der repareres sætningsskade i vejen på Pilevangen. Vejen spærres for gennemkørsel, mens arbejdet udføres. Omkørsel kan foretages via Tarupvej.
