# Når uro, opmærksomhed eller impulsivitet er en udfordring

Gruppen består af op til 16 forældre, som mødes fem gange i 2 ½ time.

Forløbet er relevant, hvis barnets udfordringer påvirker hverdagen og gør det sværere for barnet at trives eller fungere på samme niveau som jævnaldrende. Udfordringerne skal mindst vise sig derhjemme, men kan også være synlige i skole, fritid eller andre sammenhænge.

Mellem mødegangene arbejder forældrene med de redskaber og metoder, de lærer i forløbet, sammen med deres barn.

Formålet med forløbet er at give forældre viden, vejledning og konkrete redskaber, som kan styrke barnets udvikling og skabe større trivsel i familien.

Næste informationsmøde: Tirsdag den 26. januar 2027 kl. 14.00-15.30, Ørbækvej 100, indgang A, Salen.

Kom og hør mere om forløbet, og find ud af, om det er noget for jer.

Du behøver ikke tilmelde dig på forhånd. Du møder bare op.
