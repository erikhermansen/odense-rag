# Vejarbejde i Odense fra 27. april 2026

Vejarbejde i Odense fra 27. april 2026

## Trafikinfo og opstart af vejarbejde flere steder i Odense. Læs mere nedenfor.

**Høstlyngen - Vejarbejde 27. april - 2. juni**

Der udføres reparation af kloakledning på Høstlyngen. Vejen spærres for gennemkørsel, mens arbejdet udføres. Omkørsel kan foretages via Høstlyngen.

**Rødegårdsvej - Vejarbejde 27. april**

Der etableres fiber på Rødegårdsvej d. 27. april fra kl. 20.00 - kl. 05.00. Vejen spærres for gennemkørsel, mens arbejdet udføres. Omkørsel kan foretages via Dyrhøjvej og Kongshøjvej samt Melbyesvej og Eckerbergsvej.

**Rugvang - Vejarbejde 27. april - 15. maj**

Der udføres reparation af fjernvarmeledning på Rugvang. Vejen spærres for indkørsel fra Rismarksvej, mens arbejdet udføres. Omkørsel kan foretages via Rismarksvej, Tarupvej, Rugårdsvej og Kornvang.

**Rindebækvej - Vejarbejde 27. april**

Der udlægges slidlag på Rindebækvej d. 27. april kl. 07.00-18.00. Vejen spærres for gennemkørsel, mens arbejdet udføres. Omkørsel kan foretages via Ibjergvej og Svendborgvej.

**Ansgargade - Vejarbejde 28.-29. april**

Der etableres fiber på Ansgargade d. 28. og 29. april i tidsrummet kl. 19.00-05.00. Vejen spærres for gennemkørsel, mens arbejdet udføres. Omkørsel kan foretages via Søndergade.

**Odins Bro - Vejarbejde 28.-29. april**

Der udføres vedligeholdelsesarbejde på Odins Bro d. 28. - 29. april kl. 18.30-02.00. Mens der arbejdes, spærres Odins Bro for al trafik mellem Otterupvej/Næsbyvej og Tromsøgade.

**Volderslev Bygade - Vejarbejde 29.-30. april**

Der udlægges asfalt på Volderslev Bygade fra Volderslevvej til Lindvedvej. Vejen spærres for gennemkørsel, mens arbejdet udføres. Beboerkørsel er tilladt. Omkørsel kan foretages via Volderslevvej, Energivej og Svendborgvej.
