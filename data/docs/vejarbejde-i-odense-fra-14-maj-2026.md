# Vejarbejde i Odense fra 14. maj 2026

Vejarbejde i Odense fra 14. maj 2026

## Trafikinfo og opstart af vejarbejde flere steder i Odense. Læs mere nedenfor.

**Haugevej - Vejarbejde 14. - 17. maj**

Der udføres reparation af kloakledning på Haugevej. Vejen spærres for gennemkørsel, mens arbejdet udføres. Omkørsel kan foretages via Grønnegyden, Kirkegyden og Valnøddevej.

**Stigevej - Trafikinfo 18. maj**

Der udføres kranarbejde på Stigevej ved nr. 247. Mens arbejdet udføres, er Stigevej spærret for gennemkørsel fra kl. 07.00 - kl. 17.00 ved nr. 247. Omkørsel kan foretages via Kirkegyden.

**Klaus Berntsens Vej - Vejarbejde 18. - 22. maj**

Der udføres reparation af kloakledning på Klaus Berntsens Vej. Vejen spærres for gennemekørsel, mens arbejdet udføres. Omkørsel kan foretages via Højbyvej og Svendborgvej.

**Hedelundvej - Vejarbejde 18. maj - 27. juli**

Der udføres reparation af kloakledning på Hedelundvej. Vejen spærres for gennemkørsel, mens arbejdet udføres. Omkørsel kan foretages via Valnøddevej, Hæggevej og Hedelundvej.

**Hovhavevej - Vejarbejde 19. maj - 4. juni**

Der etableres ny fjernvarmestikledning på Hovhavevej. Vejen spærres for genmmemkørsel, mens arbejdet udføres. Omkørsel kan foretages via Ubberudvej, Kalørvej, Højbjergvej og Hovhavevej.
