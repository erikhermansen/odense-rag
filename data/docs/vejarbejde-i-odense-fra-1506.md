# Vejarbejde i Odense fra 15.06

Vejarbejde i Odense fra 15.06

Der startes op på vejarbejde flere steder i Odense fra den 15.6 Læs mere nedenfor.

**Lettebækvej spærres 15/6-27/6**

Fra søndag den 15. juni til fredag den 27. juni udføres der kloakarbejde på Lettebækvej, som spærres for gennemkørsel i arbejdsperioden. Omkørsel kan foretages via Hækkehusvej.

**Eranthisvej spærres 16/6-20/6**

Fra mandag den 16. juni til fredag den 20. juni skal Eranthisvej renoveres. Vejen spærres derfor for gennemkørsel ved Døckerslundsvej. Omkørsel kan foretages via Døckerslundsvej, Aurikelvej og Krokusvej.

**Billedskærevej spærres 16/6-27/6**

Fra mandag den 16. juni til fredag den 27. juni udføres der reparation af fjernvarmeledningen på Billedskærervej. Vejen spærres for gennemkørsel i arbejdsområdet. Omkørsel kan foretages via Munkerisvej, Rødegårdsvej, Klokkestøbervej og Munkebjergvej.

**Havnegade spærres 16/6-20/6**

Fra mandag den 16. juni til fredag den 20. juni udføres der etablering af kabler på Havnegade. Vejen spærres derfor for gennemkørsel i arbejdsområdet. Omkørsel kan foretages via Tromsøgade og Odins Bro..
