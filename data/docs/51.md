# 5.1 Alment

Denne arbejdsbeskrivelse omfatter ukrudtsbekæmpelse på befæstede arealer. Befæstet areal kan være befæstet med faste eller løse belægninger.

Ukrudtsbekæmpelse med brændingsmetoder må ikke udføres på flg. lokaliteter:

### Centrum:

- Møntergården, 2.449 m² fast belægning i form af brosten.
- Det Adelige Jomfrukloster, 721 m² fast belægning i form af brosten.

### Øst:

- Stige Ø– området (er tidligere losseplads, hvor der kan udsive metangas).
Området består af 5793 m2 fast belægning uden fuge, 20.694 m2 parksti samt 1850 m² faldunderlag

### Syd:

- Fællesmagasinet 709 m2 fast belægning uden fuge.
