# Vejarbejde i Odense fra 08/12

Vejarbejde i Odense fra 08/12

## Der startes op på vejarbejde flere steder i Odense. Læs mere nedenfor.

**Munkebjergvej - Vejarbejde 8/12-9/12**

Der etableres vejbump på Munkebjergvej ved rundkørslen. Vejen spærres for gennemkørsel ved arbejdet. Omkørsel kan foretages via Bjerregaardsvej, Kragsbjergvej og Chr. Sonnes Vej.

**Avenamarken - Vejarbejde 8/12 - 19/12**

Der etableres kloakledning på Avenamarken. Vejen spærres for gennemkørsel ved arbejdet. Der skiltes med omkørsel i området.
