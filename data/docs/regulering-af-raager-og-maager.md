# Regulering af råger og måger på kommunale arealer

Odense Kommune regulerer råger på bestemte tidspunkter af året på KOMMUNALE områder. Indsatserne er forskellige og udføres i samarbejde med Dansk Ornitologisk Forening, Dansk Naturfredningsforening og Jægerne i Odense.

Odense Kommune har i øjeblikket ingen reguleringsindsatser af måger på kommunale ejendomme. Du kan via linket læse, hvad du som privatperson kan gøre mod måger.

Regulering af råger og måger på private arealer er ejers ansvar.
