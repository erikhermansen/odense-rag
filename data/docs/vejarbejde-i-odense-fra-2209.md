# Vejarbejde i Odense fra 22.09

Vejarbejde i Odense fra 22.09

## Der startes op på vejarbejde flere steder i Odense fra den 22/9. Læs mere nedenfor.

**Svenstrupvej - Vejarbejde 22/9-26/9**

Fra mandag den 22/9 til fredag den 26/9 udføres der ledningsarbejde på Svenstrupvej ved Svenstrupvænget. Vejen er spærret for gennemkørsel ved arbejdet. Omkørsel kan foretages via Stenløsevej og Møllevej.

**Godthåbsgade - Vejarbejde 22/9-26/9**

Fra mandag den 22/9 til fredag den 26/9 udføres der nedtagning af tagsten på Godhåbsgade. I den forbindelse opstilles en kran, der spærrer vejen for gennemkørsel i tidsrummet fra kl. 07.00 - kl. 16.30, ved nr. 43 - 47. Omkørsel kan foretages via Lahnsgade, H.C.Andersens Gade og Jagtvej.

**Nils Erlings Allé - Vejarbedje 23/9-10/10**

Fra tirsdag den 23/9 til fredag den 10/10 udføres der fjernvarmearbejde på Nils Erlings Allé ved nr. 22. Vejen spærres for gennemkørsel ved arbejdet. Omkørsel kan foretages via Ådalsvej.
