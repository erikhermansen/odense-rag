# Vejarbejde i Odense fra 05.01

Vejarbejde i Odense fra 05.01

## Der startes op på vejarbejde flere steder i Odense i uge 2. Læs mere nedenfor.

**Rugårdsvej - Vejarbejde 5/1-/8/1**

Der udføres gravearbejde i forbindelse med udskiftning af nedløbsbrønd og stikledning ved krydset Rugårdsvej/Sandvadgyden. Vejen spærres for udkørsel til Rugårdsvej fra Sandvadgyden, mens arbejdet udføres. Omkørsel kan foretages via Korupvej, Præstevej, Elsdyrløkken og Kalørvej.

**Clausens Allé- Vejarbejde 5/1-9/1**

Der udføres reparation af sætningsskade på Clausens Allé ved nr. 12. Vejen spærres for gennemkørsel mens arbejdet udføres. Omkørsel kan foretages via Toves Allé, Benzons Allé og Rosenvænget.

**Møllevej - Vejarbejde 5/1-30/1**

Der etableres ny kloakledning på Møllevej. Vejen spærres for gennemkørsel mens arbejdet udføres. Omkørsel kan foretages via Elmebakken, Skovbakken og Pilebakken.

**Haugevej - Vejarbejde 5/1-3/4**

Der udføres reparation af kloakledning på Haugevej. Mens arbejdet udføres afvikles trafikken afvikles med signalregulering.
