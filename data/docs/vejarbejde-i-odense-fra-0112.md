# Vejarbejde i Odense fra 01.12

Vejarbejde i Odense fra 01.12

## Der startes op på vejarbejde flere steder i Odense i uge 49. Læs mere nedenfor.

**Snedkerstrede - Vejarbejde 1/12-19/12**

Der etableres overkørsel på Snedkerstrede. Vejen spærres for gennemkørseæ mens arbejdet foretages. Omkørsel kan foretages via Staupudevej.

Beboerkørsel er tilladt.

**Stat-Ene-Vej - Vejarbejde 1/12-5/12**

Der laves regnvandsstik på Stat-Ene-Vej, ved nr. 94. Vejen er spærret for gennemkørsel mens arbejdet udføres. Omkørsel kan foretages via M.P. Allerups Vej, C.F. Tietgens Blvd. og P.L.Brandts Allé.
