# Leverandører - Ældrelov og Servicelov

Leverandørerne er opdelt efter gældende lovgivning og den borgergruppe, som hjælpen er bevilget til.

- Borgere, der er fyldt 67 år, modtager hjælp efter ældrelovens bestemmelser.
- Borgere i aldersgruppen 18-67 år modtager hjælp efter servicelovens bestemmelser og visitationskriterier.

Ønsker du yderligere information om den nye Ældrelov samt de frem pleje- og omsorgsforløb i Odense Kommune, kan du læse mere her.
