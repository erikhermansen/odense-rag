# Kantinemedhjælper Odense C , ID 4602

### Virksomhed i Odense C søger en kantinemedhjælper 15-20 timer om ugen.

Dine opgaver vil bestå af:

\- Kassebetjening.

- Opvask.

- Gå med mødeforplejningsvogne til lokaler på skolen.

- Hjælpe i køkkenet med forberedelse af mad.

- Forefaldne opgaver.

### Der søges denne profil:

\- Man skal kunne gå meget og skubbe rullevogne.

- Nogle opvaskebakker kan være lidt tunge.

- Det er uddannelseskantine, så der kan være travlt i frokosttiden.

### Vær opmærksom på:

\- Det anbefales at indgå i 4 ugers praktik forud på for evt. ansættelse, for at sikre det gode match mellem dig og virksomheden i forhold til arbejdsopgaver, skånehensyn etc.”

\- I din ansøgning bedes du svare på, om du kan løse de beskrevne opgaver, og om dine timer og skånehensyn passer til jobbet

\- Hvis ansøger intet har hørt 14. dage efter ansøgningsfrist, er jobbet besat til anden side

### Postnummer

5000 Odense C.

### Antal timer

15-20 timer om ugen.

Mødedage og mødetider aftales.

Hvis du kan 15 timer om ugen, bliver der ansat 1 fleksjobber.

Hvis du kan 10-11 timer om ugen, bliver der ansat 2 fleksjobbere, som deler timerne.

### Ansøgningsfrist

24\. November 2026.

ID: 4602.
