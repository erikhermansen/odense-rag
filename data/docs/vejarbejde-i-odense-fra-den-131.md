# Vejarbejde i Odense fra den 13/1

Vejarbejde i Odense fra den 13/1

## Der skal udføres vejarbejde 2 steder i Odense. Læs nærmere nedenfor.

Skippervej 13/1 - 17/1

Der skal udføres reparation af hovedkloakledningen på Skippervej, hvorfor vejen spærres for gennemkørsel ved arbejdet. Omkørsel kan foretages via Skippervej, Lodsvej og Stigevej.

Fengersvej 13/1 - 31/1

Der skal udføres reparation af en fjernvarmeledning ved Fengersvej nr. 23. Vejen vil være spærret for gennemkørsel, mens arbejdet udføres. Omkørsel kan foretages via Chr. Sonnes Vej, Westermannsvej og Bøggildsvej.
