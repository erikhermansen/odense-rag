# Vejarbejde og trafikinfo i Odense fra 20. september 2026

## Trafikinfo og opstart af vejarbejde flere steder i Odense. Læs mere nedenfor.

**Østerbæksvej - Trafikinfo 20. september**

Der afholdes loppemarked på Østerbæksvej d. 20 september fra kl. 10.00 - kl. 17.00. Østerbæksvej spærres for gennemkørsel på den markerede strækning samt fra alle tilkørselsveje, så der ikke kan komme biler ind på strækningen.

**Eranthisvej - Vejarbejde 21. - 23. september**

Der udføres reparation af sætningsskade i vejbanen på Eranthisvej. Vejen spærres for gennemkørsel, mens arbejdet udføres. Omkørsel kan foretages via Kochsgade, Violvej og Døckerslundsvej.

**Jeppesensvej - Vejarbejde 21. september - 9. oktober**

Der udføres reparation af fjernvarmeledning på Jeppesensvej. Vejen spærres for gennemkørsel, mens arbejdet udføres. Der henvises til at følge skiltningen for omkørsel.

**Dronning Louises Vej - Vejarbejde 21. september - 9. oktober**

Der etableres nyt fjernvarmestik på Dronning Louises Vej. Vejen spærres for gennemkørsel, mens arbejdet udføres. Omkørsel kan foretages via Dronning Olgas Vej og Johannevej.

**Villestofte Skovgyde - Vejarbejde 24. september - 9. oktober**

Der etableres nyt fjernvarmestik på Villestofte Skovgyde. Vejen spærres for gennemkørsel, mens arbejdet udføres.

**Ibsensvej - Vejarbejde 24. september - 15. oktober**

Der udføres reparation af fjernvarmeledning på Ibsensvej. Vejen spærres for gennemkørsel, mens arbejdet udføres. Omkørsel kan foretages via Monbergsvej, Carl Lunds Vej og Vilheminevej.
