# Vejarbejde i Odense fra 27/1

Vejarbejde i Odense fra 27/1

## Trafikinfo og opstart af vejarbejde flere steder i Odense. Læs mere nedenfor.

**Lindvedvej - Vejarbejde 27/1 - 29/1**

Der udføres ombygning af overkørslen på Lindvedvej ved jernbanen. Vejen spærres for gennemkørsel, mens arbejdet udføres.

**Frederiksgade - Trafikinfo 29/1**

Der udføres tv-inspektion i vejbrønd på Frederiksgade. Vejen er spærret for gennemkørsel ved inspektionen fra d. 29. januar kl. 19.00 - 30. januar kl. 05.00.

**Kaalundsvej - Trafikinfo 29/1 - 30/1**

Der laves filmoptagelse på Kaalundsvej. Vejen spærres derfor for gennemkørsel ved optagelsen. Beboerkørsel er tilladt. Omkørsel kan foretages via Læssøegade og Chr. Richards Vej
