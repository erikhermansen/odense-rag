# Vejarbejde i Odense fra 13.10

Vejarbejde i Odense fra 13.10

## Der startes op på vejarbejde flere steder i Odense i uge 42. Læs mere nedenfor.

**Rugårdsvej - Vejarbejde 12/10-24/10**

Der udføres reparation af fjernvarmeledning på Rugårdsvej. Trafikken afvikles med prioritering ved arbejdet.

**Skjoldborgsvej - Vejarbejde 13/10-17/10**

Der udskiftes en defekt vejbrønd på Skjoldborgsvej. Vejen spærres for gennemkørsel ved arbejdet. Omkørsel kan foretages via Skolevej og Firkløvervej.

**Jeppe Aakjærs Alle - Vejarbejde 13/10-17/10**

Der udføres reparation af sætningsskade i kørebanen på Jeppe Aakjærs Allé. Vejen spærres for gennemkørsel ved arbejdet. Omkørsel kan foretages via Rugårdsvej og Eddavej.
