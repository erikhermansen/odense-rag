# Vejarbejde og trafikinfo i Odense fra 3. oktober 2026

## Trafikinfo og opstart af vejarbejde flere steder i Odense. Læs mere nedenfor.

**Odensevej - Vejarbejde 3. - 4. oktober**

Jernbaneoverkørslen på Odensevej bygges om. Vejen spærres for gennemkørsel, mens arbejdet udføres. Omkørsel kan foretages via Svendborgvej og Hjallesegade.

**Gammel Højmevej - Vejarbejde 5. - 9. oktober**

Der udføres reparation af fjernvarmeledning på Gammel Højmevej. Vejen spærres for gennemkørsel, mens arbejdet udføres. Omkørsel kan foretages via Gammel Højmevej, Brændekildevej, Assensvej og Højmevej.

**Kochsgade mm. - Vejarbejde 5. - 23. oktober**

Der udføres strømpeforing af hoved- og stikledninger på Kochsgade, Fabersgade, Grønlandsgade, Danmarksgade og Skt. Jørgens Gade. Der henvises til at orientere sig efter den opstillede skiltning og køre efter forholdene.

**Nonnebovej - Trafikinfo 5. - 6. oktober**

Der udføres træfældning på Nonnebovej. Vejen spærres for gennemkørsel, mens arbejdet udføres.

**Sanderumgårdvej (1) - Trafikinfo 7. oktober**

Der udføres træfældning på Sanderumgårdvej. Vejen spærres for gennemkørsel, mens arbejdet udføres.

**Sanderumgårdvej (2) - Trafikinfo 8. - 9. oktober**
