# Vejarbejde i Odense fra 27/10

Vejarbejde i Odense fra 27/10

## Der startes op på vejarbejde flere steder i Odense i uge 44. Læs mere nedenfor.

**Tolderlundsvej - Vejarbejde 27/10-7/11**

Der udføres reparation af fjernvarmeledning på Tolderlundsvej. Vejen spærres for gennemkørsel i retning mod Thomas B. Thriges Gade, på stykket mellem Buchwaldsgade og Thomas B. Thriges Gade.

**Fredensgade - Vejarbejde 27/10-31/10**

Der udføres reparation af fjernvarmeledning på Fredensgade. Vejen spærres for gennemkørsel ved arbejdet. Der skiltes med omkørsel i området.

**Borsvinget - Vejarbejde 27/10-7/11**

Der udføres reparation af fjernvarmeledning på Borsvinget. Vejen spærres for gennemkørsel mens arbejdet udføres. Omkørsel kan foretages via Lunden og Mellemhaverne.
