# Vejarbejde i Odense fra 20.10

Vejarbejde i Odense fra 20.10

## Der startes op på vejarbejde flere steder i Odense i uge 43. Læs mere nedenfor.

**Klokkestøbervej - Vejarbejde 20/10-24/10**

Der udføres reparation af sætningsskade på Klokkestøbervej. Vejen spærres for gennemkørsel ved arbejdet. Arbejdet forventes at tage en dag. Omkørsel kan foretages via Rødegårdsvej, Stenhuggervej og Billedskærervej.

**Grevelundsvej - Vejarbejde 20/10-14/11**

Der etableres ny vandledning på Grevelundsvej. Vejen spærres for gennemkørsel ved arbejdet. Omkørsel kan foretages via Nyborgvej og Østre Ringvej.

**Spedsbjergvej - Vejarbedje 20/10/25-8/6/26**

Der etableres ny jernbane over Vestfyn. I den forbindelse spærres Spedsbjergvej for gennemkørsel. Omkørsel kan foretages via Middelfartvej, Ravnebjerggyden og Bøllemosegyden.

**Stat-Ene-Vej - Vejarbejde 20/10-21/11**

Der arbejdes på udvidelse af krydset på Stat-Ene-Vej. Vejen spærres for gennemkørsel mens arbejdet udføres. Omkørsel kan foretages via C. F. Tietgens Boulevard og M. P. Allerups Vej.
