# Vejarbejde i Odense fra 6/10

Vejarbejde i Odense fra 6/10

## Der startes op på vejarbejde flere steder i Odense i uge 41. Læs mere nedenfor.

**Møllevej - Vejarbejde 6/10-31/10**

Der udføres kloakarbejde på Møllevej, ved nr. 36 - 40. Vejen spærres for gennemkørsel ved arbejdet. Omkørsel kan foretages via Birkebakken, Skovbakken og Pilebakken.

**Hermelinløkken - Vejarbejde 6/10-10/10**

Der etableres to nye kloakstikledninger på Hermelinløkken. Vejen spærres for gennemkørsel ved arbejdet. Omkørsel kan foretages via Hermelinløkken.

**Kong Georgs Vej - Trafikinfo 6/10**

Kong Georgs Vej spærres midlertidigt for trafik ved Ny Kongevej, da der afholdes indvielse af fodgænger- og cykelzonen ved Åløkkeskovej. Det foregår fra kl. 7.30 - kl. 14.00.

**Skt. Gertruds Stræde - Vejarbejde 8/10-31/10**

Der etableres tryghedsskabende foranstaltninger med opsætning af pullerter ved Skt. Gertruds Stræde. Mens arbejdet foretages spærres vejen for gennemkørsel
